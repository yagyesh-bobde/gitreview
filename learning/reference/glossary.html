GitReview — Glossary

Plain-English definitions of the words that come up across every lesson. Keep this open.

App Router

The modern way Next.js organizes a website: every folder under src/app/ becomes a URL.

In this repo, the folder app/(app)/[org]/[repo]/pull/[id]/ becomes the URL /twofourlabs/app-kavana/pull/255.

Server Component vs Client Component

A Server Component runs on the server and sends finished HTML. A Client Component runs in the browser and can react to clicks/typing.

Rule of thumb here: the page shell + first data load is server-rendered; anything interactive (file tree clicks, AI bar) is a client component.

OAuth

A way to log in using another service ("Sign in with GitHub") without ever giving GitReview your GitHub password.

GitHub hands GitReview a token — a temporary key that lets the app act on your behalf.

Token

A secret string that proves "this request is allowed." GitReview stores your GitHub token and sends it with each API call.

REST API

GitHub's menu of web addresses you can call to get data (list PRs, get a diff, post a comment). GitReview talks to it over HTTPS.

Cache

A fast, temporary copy of data so you don't re-ask GitHub for the same thing. GitReview uses Redis (via Upstash) for this.

Stale-While-Revalidate (SWR)

"Show the slightly-old copy instantly, then quietly fetch a fresh one in the background." Makes the app feel fast.

See it live in src/app/api/github/prs/route.ts.

TanStack Query

A browser library that fetches data, caches it, and re-fetches when needed — so components just say "give me the PR files" and don't manage loading state by hand.

TanStack Virtual (virtualization)

Only draws the rows currently on screen. A 5,000-line diff stays smooth because the browser renders ~30 visible lines, not all 5,000.

Shiki

The tool that colors code (syntax highlighting), using the same engine as VS Code. Runs as WASM in the browser.

Zustand

A tiny "shared whiteboard" for the browser. Different parts of the UI read/write the same state (e.g. "which file is selected") without passing props everywhere.

Drizzle ORM

A type-safe way to talk to the database in TypeScript instead of raw SQL. Pairs with Neon (a cloud Postgres database).

Hunk

One contiguous block of changed lines in a diff (the chunks GitHub shows with the @@ ... @@ header). Diffs are rendered hunk by hunk.

Feature module

A self-contained folder under src/features/ (auth, github, diff-viewer, ai-bar…). Each owns its components, hooks, and logic. They talk through Zustand stores, never by importing each other.
